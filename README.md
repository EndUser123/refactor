# refactor

Multi-file refactoring orchestrator with TDD support for Claude Code.

## Overview

This package provides automated multi-file refactoring capabilities with:
- Discovery of refactoring opportunities across files
- TDD (Test-Driven Development) characterization tests
- Constitutional compliance filtering
- Parallel adversarial review

## Installation

```bash
pip install .
```

For development:

```bash
pip install -e ".[dev]"
```

## Usage

This package is designed to be used within Claude Code as a skill.
